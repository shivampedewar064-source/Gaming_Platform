    Rules

  • The game is played on a 3×3 grid.
  • One player is X and the other is O.
  • The first player to get 3 in a row (horizontal, vertical, or diagonal) wins.
  • If all boxes are filled and no one has 3 in a row, it’s a draw.
  • Players cannot place a mark on a spot that is already taken.
