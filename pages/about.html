What is this?

A static-first gaming hub containing six vanilla JavaScript games. Everything is organized for instant hosting on Firebase, Netlify, Vercel, GitHub Pages, or Firebase Hosting.

  • Games live in /games/<game-name>
  • Shared assets and scripts live in /assets
  • Pages such as login and about use /pages

Tech stack

  • Vanilla HTML, CSS, and JavaScript
  • Firebase Authentication (compat SDK)
  • Firebase Hosting routing rules
  • Optional deploys to Netlify / Vercel

Deployment checklist

  • Copy Firebase keys into assets/js/firebase-config.js
  • Run firebase init hosting (once)
  • Deploy via firebase deploy or drag-and-drop to Netlify
  • Use firebase.json rewrites for single entry routing
