    Rules

  • Fill the grid The Sudoku board is a 9×9 grid, divided into 3×3 sub-grids called boxes. Fill the empty cells with numbers from 1 to 9.
  • No repetition in any ROW Each row must contain the numbers 1 through 9 only once. No duplicates allowed.
  • No repetition in any COLUMN Each column must contain the numbers 1 through 9 only once.
  • No repetition in any 3×3 BOX Each 3×3 box must have the numbers 1 to 9 only once, no repeats.
